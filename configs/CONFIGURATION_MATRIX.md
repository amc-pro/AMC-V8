# AuctionMarketCore V8.0 — Configuration Matrix

The project is now exclusively dedicated to the **ScalpingPro** preset across 8 supported instruments.

## Supported Instruments
- `NQ`: Nasdaq 100 E-mini (Futures CME)
- `MNQ`: Micro E-mini Nasdaq-100 (Futures CME)
- `ES`: S&P 500 E-mini (Futures CME)
- `MES`: Micro E-mini S&P 500 (Futures CME)
- `GC`: Gold Full Contract (Futures COMEX)
- `MGC`: Micro Gold (Futures COMEX)
- `CL`: Crude Oil Full Contract (Futures NYMEX)
- `MCL`: Micro WTI Crude Oil (Futures NYMEX)

## Presets
- `SCALPING_PRO`: Premium production trading mode with SMC Confluence, Footprint Evidence validation, Dynamic ATR stops, and Closed-Reference VWAP extreme confluence.

Legacy presets (`SCALPING`, `SNIPER`, `SCANNER`, `STANDARD`) have been removed to specialize the repository strictly for ScalpingPro execution.
